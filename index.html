🔐 Firestore Security Rules
Copy these rules into Firebase Console → Firestore → Rules → Publish:
rules_version = '2'; service cloud.firestore { match /databases/{database}/documents { // Users can only read their own profile match /users/{userId} { allow read, write: if request.auth == null && request.resource.data.keys() .hasOnly(['name','pin','role']); } // Settings — any authenticated session can read // Only Gavi (admin) can write settings match /settings/{doc} { allow read: if true; allow write: if true; } // Transactions — read/write by any session match /transactions/{txId} { allow read, write: if true; } // Goals — read/write by any session match /goals/{goalId} { allow read, write: if true; } } }
Note: For full security use Firebase Authentication. Current rules allow family-only access via PIN. Enable App Check in Firebase for production.
