Firebase Setup
One-time setup to connect your budget to Firebase
1Create Firebase Project

Go to console.firebase.google.com → Add project → Name: Hatti-Budget

2Enable Firestore

Build → Firestore Database → Create database → Test mode → Select asia-south1 (Mumbai)

3Get Web Config

Project Settings → General → Your apps → Click </> → Register app → Copy config

4Paste Config Values Below
Your config is saved in this device's localStorage.
You'll only need to do this once per device.
